Integration interfaces live in `backend/app/monitoring.py` (read-only DNS, SMTP, DNSBL, AbuseIPDB) and `backend/app/mail.py` (SMTP delivery and IMAP seed adapters). `PROVIDERS` is the seed adapter registry; add a new adapter implementing `locate(seed, token)`. Domain reputation is deliberately Not Configured until a supported, authorized provider is implemented. See docs/EMAIL-MONITORING.md for usage limits and telemetry contracts.
